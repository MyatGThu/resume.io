# awesome-design-md

Static reference files, vendored from https://github.com/VoltAgent/awesome-design-md
(commit f696123, MIT License, see LICENSE). No scripts, no network access.

Each folder in `references/` holds one `DESIGN.md`: YAML front matter with tokens
(colors, typography, spacing, radii, shadows, components) followed by prose on the
brand's visual language, layout, components and do's and don'ts. They follow the
Google Stitch DESIGN.md format, the same shape as this project's own `DESIGN.md`.

## How to use

1. Pick the two to four references closest to the job. For a dark, cinematic,
   photography-led page start with: spacex, tesla, bugatti, lamborghini, ferrari,
   playstation, runwayml, nvidia, apple. For editorial type: theverge, wired. For
   restrained product UI: linear.app, vercel, stripe, raycast.
2. Read only those files: `references/<name>/DESIGN.md`.
3. Compare, do not copy: use them to judge the project's own system (type scale
   steps, contrast, spacing rhythm, component states, how rules are written) and
   to name concrete gaps. This project's identity comes from its own DESIGN.md.
